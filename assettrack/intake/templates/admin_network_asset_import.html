Use Import Assets

This Switch/Router CSV guidance is deprecated for operator use. Use Import Assets for bulk asset imports. Import Assets supports CSV and XLSX files for supported asset records with analysis, preview, explicit confirmation, atomic commit, and results.

Open Import Assets

Download Import Assets CSV template

Import command Run from the AssetTrack project
python scripts/import_network_assets_csv.py path/to/network_switch_router_staging_template_v1.csv --db data/assettrack.db --actor admin

Review the CSV before running. The importer validates rows and stops on errors.

CSV requirements Custody fields only

Allowed columns:

  • asset_tag, barcode, serial_number
  • equipment_type: Laptop, Switch, Router, Server, Storage, Firewall, NTP, or KVM
  • manufacturer, model, location_building
  • case_identifier, slot_identifier, notes_comments

Do not add IP address, MAC address, VLAN, switch port, topology, patch panel, firmware, monitoring, configuration, or CMDB relationship data.

Validation Existing behavior

Duplicate asset tags and serial numbers are rejected before import.

Unsupported equipment types are rejected. Empty slots must already exist before assignment.

No upload page is provided here; use the validated command-line path.
